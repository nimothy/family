# The Andersons

A static website with the illustrated homepage at `/`, the blog at `/blog/`, and all 19 posts beneath `/blog/`.

Upload `index.html`, `assets/` and `blog/` to a static host that serves directory `index.html` files. No build step, PHP, database or WordPress installation is needed.

`assets/` contains styles, the font, illustration and blog photos. Each post lives in `blog/honeymoon-day-*/index.html`, with its linked photo pages alongside it. Existing comments are displayed; adding posts means editing the HTML files.
